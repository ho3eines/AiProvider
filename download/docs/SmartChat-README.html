Section 01
معرفی پروژه | Overview

این پروژه یک اپلیکیشن چت هوشمند کامل است که با هدف کار با سرویس رایگان freemodels ساخته شده است. رابط کاربری دقیقاً به سبک ابزارهای مدرن چت AI طراحی شده — تم تاریک، چیدمان راست‌به‌چپ فارسی، فونت Vazirmatn، پیکر مدل گروهی با لوگوی واقعی ارائه‌دهنده‌ها — و پاسخ‌ها به‌صورت زنده (streaming) با نمایش فرایند تفکر مدل (reasoning) رندر می‌شوند. پروژه در قالب دو نسخهٔ موازی تحویل داده شده است که هر دو از یک آپستریم مشترک استفاده می‌کنند و رفتار یکسانی دارند.

۱) نسخهٔ Next.js — src/
اپ کامل React 19 با Tailwind CSS 4 و کامپوننت‌های client-side؛ مناسب توسعهٔ آینده، پیش‌نمایش زنده و استقرار استاندارد. نقطهٔ ورود UI فایل src/app/page.tsx و بک‌اند در مسیرهای src/app/api/* و src/app/v1/* است.
۲) نسخهٔ تک‌فایل — app.js
یک فایل CommonJS خالص Node (بدون هیچ وابستگی خارجی) که سرور HTTP، پروکسی، API سازگار OpenAI/Anthropic و کل رابط کاربری را در قالب HTML رشته‌ای داخل همان فایل سرو می‌کند؛ با node app.js روی هر ماشینی بدون npm install اجرا می‌شود.

هر دو نسخه علاوه بر رابط چت، یک API کامل سازگار با OpenAI و Anthropic نیز ارائه می‌دهند (/v1/models، /v1/chat/completions، /v1/messages) تا از هر کلاینت استانداردی — SDK رسمی، curl، ابزارهای شخص ثالث — بتوان به مدل‌های سرویس دسترسی داشت. احراز هویت با کلیدهای سبک OpenAI و Anthropic انجام می‌شود که به‌صورت خودکار ساخته و در api-keys.json ذخیره می‌گردند.

۴.۲ — اتصال آپستریم | Upstream Connection

  • URL آپستریم: https://freemodels-chat.freemodels.workers.dev/ — ثابت در src/lib/upstream.ts و معادلش در app.js.
  • جعل هدرهای مرورگر: Origin: https://freemodels.pro، Referer: https://freemodels.pro/، UA کروم ویندوزی، کامل sec-ch-* و sec-fetch-*، و Accept-Encoding: identity تا پاسخ فشرده نباشد و pipe مستقیم بدون decompress ممکن شود.
  • چرا node:https؟ مرورگرها و fetch ارسال دستی Origin/Referer را ممنوع می‌کنند؛ برای عبور از CORS آپستریم باید این هدرها واقعاً روی سیم برود. این تصمیم در Task 1 گرفته شد و در هر دو نسخه رعایت شده است.
  • پایداری استریم: پاسخ تکه‌به‌تکه (بدون تجمیع بافر) رد می‌شود؛ Cache-Control: no-cache, no-transform و X-Accel-Buffering: no ست می‌شود تا پروکسی‌های میانی بافر نکنند. قطع کلاینت ← destroy فوری آپستریم.

Section 05
قابلیت‌ها | Features

۵.۱ — رابط چت | Chat UI

  • چیدمان: سایدبار راست 260px (چت جدید، لیست گفتگوها با حذف، خروجی Markdown/JSON، پاک‌کردن همه با confirm) + drawer موبایل؛ هدر کنترل‌ها؛ کامپوزر چسبان.
  • پیکر مدل گروهی (مطابق HTML واقعی سایت freemodels): سه گروه «Claude Pro / ChatGPT Pro / Other Pro Models» با آیکن‌های lucide، لوگوی 20px گردگوشه، ردیف انتخاب‌شدهٔ تیره #0A0A0B با تیک، hover #FFFBF5، اسکرول داخلی، تارگت لمسی 44px، بستن با کلیک بیرون و Esc.
  • کنترل‌های هدر: تفکر · جست‌وجوی عمیق · استریم · دکمهٔ «اتصال؟» با ping خودکار · پنل Raw SSE (80KB) · مودال ⚙️ با System Prompt و بخش «🔑 اندپوینت‌های API و کلیدها» (کلیدها + کپی + نمونه curl) · نشانگر وضعیت سبز/زرد/قرمز.
  • پیام‌ها: اکشن‌های hover (کپی/ویرایش اینلاین کاربر با حذف پیام‌های بعدی/حذف/بازتولید ↻)، باکس جمع‌شوندهٔ «💭 فرایند تفکر مدل»، آمار ⏱/🧩/✍️، نشان «⏹ متوقف شد»، حباب قرمز خطا.
  • استریم زنده: flush با requestAnimationFrame، کرسر چشمک‌زن، دکمهٔ ارسال ↔ توقف (⏹ + Esc با AbortController) و destroy واقعی آپستریم.
  • حافظه: localStorage با کلیدهای fm_chats / fm_settings؛ بارگذاری بعد از mount (بدون hydration mismatch)؛ صفحهٔ خوش‌آمد با ۴ پیشنهاد.

۵.۲ — مارک‌داون و کد | Markdown & Code

رندرر مارک‌داون دست‌ساز و امن است: ابتدا escape کامل HTML و سپس درج کنترل‌شدهٔ تگ‌ها. بلوک‌های کد با placeholder جداسازی می‌شوند و هدر زبان + دکمهٔ «کپی» + هایلایت سینتکس ساده (کلیدواژه/رشته/عدد/کامنت) + dir=ltr دارند؛ کد اینلاین، بولد/ایتالیک/خط‌خورده/لینک (target=_blank)، هدینگ‌ها، لیست‌ها، نقل‌قول و خط افقی هم پشتیبانی می‌شوند. این منطق در src/lib/markdown.ts و معادلش در PAGE_JS یکسان است.

۵.۳ — سرور API | API Server

هر دو نسخه سه اندپوینت استاندارد + دو مسیر داخلی را سرو می‌کنند (جزئیات بخش ۷) و خطاها را دقیقاً در فرمت JSON همان API مقصد برمی‌گردانند — error.message/type/code برای OpenAI و error.type/message برای Anthropic. همهٔ مسیرها CORS باز شامل هدرهای احراز هویت دارند.

۷.۵ — POST /v1/chat/completions — سازگار OpenAI

  • فیلدها: model (نرمال نرم؛ خالی ← پیش‌فرض)، messages (اجباری)، stream، stream_options.include_usage + دو اکستنشن غیراستاندارد: thinking و deep_search.
  • غیراستریم: آبجکت کامل chat.completion با choices[].message.content و usage تخمینی (~۴ نویسه = ۱ توکن).
  • استریم: چانک نقش ← دلتاها (content و در صورت وجود reasoning_content) ← چانک finish_reason:"stop" ← چانک usage (در صورت include_usage) ← data: [DONE].
curl -N http://localhost:3000/v1/chat/completions \
  -H "Authorization: Bearer sk-ItqvFVBt8slw2vqxPuW9oLiSyGGgC29lNYeET64dIzJ04e50" \
  -H "Content-Type: application/json" \
  -d '{"model":"claude-fable-5.1","messages":[{"role":"user","content":"سلام"}],"stream":true}'

۷.۶ — POST /v1/messages — سازگار Anthropic

  • طبق قوانین Anthropic فیلدهای model و max_tokens اجباری‌اند (نبود ← 400 با پیام "model: Field required" / "max_tokens: Field required").
  • system به‌صورت رشته یا آرایهٔ بلوک پذیرفته می‌شود و به یک پیام system تبدیل می‌گردد.
  • غیراستریم: آبجکت message با بلوک‌های {type:"thinking"} (در صورت وجود) و {type:"text"} + stop_reason:"end_turn" + usage.
  • استریم: چرخهٔ کامل message_start → ping → (content_block_start + content_block_delta با thinking_delta/text_delta + content_block_stop)* → message_delta → message_stop.
curl -N http://localhost:3000/v1/messages \
  -H "x-api-key: sk-ant-api03-9lamB2K7KoYT8fw8tAp2CKL5kKsOHKhN4mE9eawuzRuW0aU3umJirsEFbS3B6RCjLRw8lrJ0YRmsnxECIu3nHaKM" \
  -H "anthropic-version: 2023-06-01" -H "Content-Type: application/json" \
  -d '{"model":"claude-fable-5.1","max_tokens":1024,"messages":[{"role":"user","content":"سلام"}],"stream":true}'

مشکلات شناخته‌شده و نقشهٔ راه | Known Issues & Roadmap

۹.۱ — مشکلات شناخته‌شده | Known Issues

  • خطای موقت 429 آپستریم («providers exhausted» / «Service temporarily overloaded»): رفتار سرویس رایگان است، نه باگ پروژه. هر دو نسخه آن را شفاف به حباب قرمز (UI) یا کد/فرمت استاندارد (API) تبدیل می‌کنند و retry پس از چند ثانیه معمولاً موفق است.
  • فرمت پاسخ آپستریم قفل به سبک OpenAI فعلی است: پارسر sse.ts جهانی طراحی شده، اما اگر آپستریم ساختارش را تغییر دهد اولین نقطهٔ بررسی همین فایل (و معادل makeUpstreamParser در app.js) است.
  • وابستگی فونت به شبکه در نسخهٔ Next: فونت Vazirmatn با لینک مستقیم Google Fonts لود می‌شود (تصمیم عمدی برای مقاومت به قطعی نصب)؛ در محیط بدون اینترنت UI با فونت جایگزین رندر می‌شود. نسخهٔ app.js این مشکل را ندارد.
  • usage تخمینی است (~۴ نویسه = ۱ توکن) چون آپستریم usage واقعی نمی‌دهد.

۹.۲ — مسیر پیشنهادی ادامه | Roadmap

  • Retry خودکار با backoff برای 429 آپستریم در لایهٔ پروکسی — بهترین بهبود تجربهٔ کاربر.
  • افزودن فیلدهای group/vendor به /v1/models به‌صورت extension اختیاری (سازگاری OpenAI حفظ می‌شود).
  • استقرار پروداکشن: bun run build + اجرای standalone پشت reverse proxy (با X-Accel-Buffering: no) یا node app.js با systemd/pm2.
  • تست‌های خودکار: اسکریپت smoke برای ۶ مسیر (فعلاً چک‌لیست دستی در HANDOFF.md § 5).
  • چندکاربره‌سازی (اختیاری): محدودسازی نرخ و احراز هویت جدا برای /api/chat در صورت عمومی‌شدن اپ.
