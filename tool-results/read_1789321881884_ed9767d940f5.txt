     1→   401→```css
     2→   402→.vline {

    13→   413→- [ ] Every vertical line’s height matches its adjacent text block span
    14→   414→- [ ] Every horizontal line’s width ≥ widest text element in its zone
    15→   415→- [ ] No decorative line is shorter than the text it accompanies

    18→   418→
    19→   419→## S3.8 - Vertical Balance (Anti-Top-Heavy Layout)
    20→   420→
    21→   421→**Problem:** Content clusters at top of page, bottom 40%+ is dead whitespace.
    22→   422→
    23→   423→**Rule:** When total content height < 50% of page height, switch to centered distribution (flexbox `justify-content: center`). Otherwise use anchor grid:
    24→   424→
    25→   425→| Content Volume | Title Anchor | Summary Anchor | Meta Anchor |
    26→   426→|---------------|-------------|----------------|-------------|
    27→   427→| **Sparse** (fill < 50%) | Centered mode | Centered mode | Centered mode |
    28→   428→| **Normal** (fill 50-80%) | `H * 0.30` | `H * 0.48` | `H * 0.70` |
    29→   429→| **Dense** (fill > 80%) | `H * 0.20` | `H * 0.40` | `H * 0.65` |
    30→   430→
    31→   431→**CJK Title Size Compensation:** CJK characters appear smaller at same pt size. Increase by 15-20%:
    32→   432→- CJK Hero Title: 50-80pt (Latin: 45-65pt)
    33→   433→- CJK Kicker: 11-12pt (Latin: 9pt)
    34→   434→- CJK Summary: 17-20pt (Latin: 16-18pt)
    35→   435→
    36→   436→**Checklist:**
    37→   437→- [ ] No cover has >40% dead whitespace at the bottom
    38→   438→- [ ] CJK titles are 15-20% larger than equivalent Latin titles
    39→   439→- [ ] Sparse-content covers use centered distribution
    40→   440→
    41→   441→---
    42→   442→
    43→   443→## S3.9 - Percentage Positioning Requires Known-Size Container
    44→   444→
    45→   445→**Problem:** `top: XX%` resolves against containing block’s height. If height is undefined (all children absolutely positioned), percentages collapse and elements stack.
    46→   446→
    47→   447→**Iron rule:** Container with `top: XX%` children MUST have deterministic height (`height: 100%`, `inset: 0`, or `top` + `bottom` pair).
    48→   448→
    49→   449→```css
    50→   450→/* ✅ Safest: flat structure with px values */
    51→   451→.cover { position: relative; width: 794px; height: 1123px; }
    52→   452→.kicker { position: absolute; top: 225px; left: 95px; }
    53→   453→.title  { position: absolute; top: 292px; left: 95px; }
    54→   454→
    55→   455→/* ✅ OK: wrapper with inset:0 gives it known height */
    56→   456→.content-left { position: absolute; inset: 0; width: 55%; }
    57→   457→.title { position: absolute; top: 26%; }  /* 26% of 1123px ✓ */
    58→   458→
    59→   459→/* ❌ BANNED: wrapper without height, percentage is undefined */
    60→   460→.content-left { position: absolute; left: 12%; top: 0; width: 55%; }
    61→   461→.title { position: absolute; top: 26%; }  /* 26% of WHAT? → overlap */
    62→   462→```

   479→   879→**Layout rules:**
   480→   880→1. **Border frame**: 2.5pt solid black, inset ~5% from all page edges (40px left/right, 56px top/bottom on A4 at 96dpi). This is the defining visual element.
   481→   881→2. **Institution name**: Centered, serif, 28-34pt Bold, letter-spacing 4-6px. For CJK names, use wider letter-spacing (6px). For Latin names, use standard (3px).
   482→   882→3. **Thick divider**: 2pt solid line, 70% width, separates institution from content below.
   483→   883→4. **Document type**: 20-24pt, lighter weight than institution name, letter-spacing 3-4px. This slot differentiates document categories (e.g. "开题报告" / "Thesis Proposal" / "毕业论文" / "Graduation Design").
   484→   884→5. **Title**: Serif, 26-30pt Bold, max 3 lines, centered. Auto-wrap at 520px width.
   485→   885→6. **Structured fields**: Left-aligned label + centered underline value. Label width fixed by longest label in the set. 3-7 field rows supported. Common fields: Name/姓名, Student ID/学号, Advisor/导师, Department/院系, Major/专业.
   486→   886→7. **Date**: Centered at bottom, 14pt, letter-spacing 2px.
   487→   887→
   488→   888→**Field auto-detection:**
   489→   889→When the user provides structured metadata (name, student ID, advisor, etc.), auto-populate the fields block. When no fields are provided, omit the fields-block entirely and let the title expand vertically into the freed space.
   490→   890→
   491→   891→**Variant 06B - Double border:**
   492→   892→For extra formality (government documents, official submissions), replace the single border with a double border (outer 2.5pt + inner 1pt, 6px gap):
   493→   893→```css
   494→   894→.border-frame {
   495→   895→  border: 2.5px solid var(--c-accent);
   496→   896→  outline: 1px solid var(--c-accent);
   497→   897→  outline-offset: 6px;
   498→   898→}
   499→   899→```
